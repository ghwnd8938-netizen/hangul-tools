엑셀 CSV 한글 깨짐 고치기

CSV 파일의 인코딩을 확인해 엑셀에서 한글이 깨지지 않는 UTF-8(BOM) 파일로 바꿔 줍니다.

CSV·TSV·TXT 파일을 여기에 끌어다 놓거나 아래에서 선택하세요.

-

미리보기의 한글이 깨져 보이면 다른 인코딩을 골라 보세요.

미리보기 (처음 10행)

내용과 줄바꿈은 그대로 두고 인코딩만 바꿉니다. BOM 없는 파일은 구글 시트·프로그램용입니다.

파일은 서버로 전송되지 않고 이 브라우저 안에서만 처리됩니다. 방문 수만 쿠키 없이 익명으로 셉니다(Cloudflare Web Analytics).

왜 엑셀에서 한글이 깨지나요?

CSV는 글자만 담긴 텍스트 파일이라, 어떤 인코딩으로 저장했는지 파일 안에 적혀 있지 않습니다. Windows용 엑셀은 CSV를 더블클릭해 열 때 파일 맨 앞에 UTF-8 표시(BOM, 바이트 EF BB BF)가 없으면 시스템 기본 코드 페이지, 한국어 Windows에서는 CP949로 읽습니다. 그런데 구글 시트를 비롯한 많은 웹 서비스와 프로그램은 CSV를 BOM 없는 UTF-8로 내보냅니다. 이 파일을 CP949로 읽으면 ‘이름’이 ‘?대쫫’처럼 알아볼 수 없는 글자로 보입니다.

반대로 오래된 업무 시스템이나 한국어 Windows 엑셀의 ‘CSV (쉼표로 분리)’ 저장은 CP949로 파일을 만드는 경우가 많아, 이런 파일은 구글 시트나 프로그램에서 깨집니다. 어느 쪽이든 UTF-8로 바꾸고 엑셀용이면 BOM을 붙이면 됩니다.

사용 방법

  1. 파일을 끌어다 놓거나 ‘파일 선택’으로 고릅니다.
  2. 감지된 인코딩과 미리보기를 확인합니다. 한글이 깨져 보이면 ‘인코딩 직접 선택’을 바꿔 봅니다.
  3. 엑셀에서 열 파일이면 ‘엑셀용으로 저장’, 구글 시트나 프로그램에서 쓸 파일이면 ‘BOM 없음’으로 저장합니다.

자주 묻는 질문

내용이 바뀌지는 않나요?
글자, 쉼표, 따옴표, 줄바꿈 방식(CRLF/LF)은 그대로 두고 인코딩과 BOM만 바꿉니다.
CP949(EUC-KR)로 바꾸는 기능은 없나요?
브라우저에 내장된 문자 인코더는 UTF-8만 지원해서 제공하지 않습니다. Excel 2016 이상(Microsoft 365 포함)은 BOM이 붙은 UTF-8 CSV를 정상적으로 엽니다.
BOM 없는 UTF-8은 언제 쓰나요?
구글 시트는 BOM이 없어도 UTF-8로 읽습니다. 일부 프로그램이나 스크립트는 BOM을 첫 칸 글자의 일부로 읽어 첫 열 이름이 달라지므로, 그런 곳에는 BOM 없는 파일이 낫습니다. 맥용 엑셀도 BOM이 없으면 한글이 깨질 수 있으니 엑셀에서 열 파일은 ‘엑셀용’으로 저장하세요.
변환했는데도 깨져요.
글자가 ‘?’나 ‘�’로 바뀐 채 저장된 파일은 원래 정보가 사라져 되돌릴 수 없으니, 원본 파일을 다시 받아 변환하세요. 엑셀의 ‘데이터 → 텍스트/CSV에서’ 가져오기를 쓰면 인코딩을 직접 고를 수도 있습니다.

한계

  • 자동 감지는 추정입니다. UTF-8 규칙에 맞으면 UTF-8, 아니면 CP949로 봅니다. 한글이 거의 없는 짧은 파일이나 Shift_JIS·GBK 같은 다른 나라 구형 인코딩은 잘못 판단할 수 있습니다.
  • UTF-16 파일(엑셀 ‘유니코드 텍스트’)은 BOM이 있거나 영문·숫자가 섞여 있을 때만 인식합니다.
  • 엑셀 통합 문서(.xlsx)는 텍스트 파일이 아니라서 처리하지 않습니다.
  • 파일 전체를 브라우저 메모리에서 처리하므로 수백 MB 이상은 느리거나 실패할 수 있습니다.
