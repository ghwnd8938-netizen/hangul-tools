[Scoring rules (this book's practice rubric, 5 points per blank; the caps and the -1/-2 deductions are this book's, not official TOPIK values)]
Check in the order of rule 2: context and meaning, sentence type, style and honorifics, then grammar, spelling and spacing. Each blank starts at 5 points. If a rule says "at most" or "only", first cap the score there; if several caps apply (W01, W05, W06), use the lowest cap. Then deduct once for each other problem, as below. If the same code applies to two different problems, deduct twice (except W09). Different problems count separately even when they sit in the same words (e.g., '주세요' is both a command form, W04, and a -요 ending, W02). One problem is never counted under two codes (e.g., do not add W07 for a word you already counted under W01). Minimum 0. A blank left empty, or written in a language other than Korean: 0 points.
W01 Meaning does not fit the context: this blank gets only 0 to 1 points. 0 points if it does not make sense, is off topic, or says the opposite of what it should (e.g. '통장 사본을 봉투에 잘 넣었습니다': it should say the copy was not put in, but it says it was put in properly). 1 point if it reads naturally, is on topic and does not say the opposite, but contradicts a fact in the text (e.g. '통장 사본을 잃어버린 것 같습니다': the text says the copy is still in the bag, so it was not lost).
W02 The text uses '-습니다', but the blank uses a '-요' ending such as '-아/어요' or '-(으)세요': -2. Only '-(으)ㄹ까요': -1. Asking the boss to do something without '-시-' (e.g. '넣어 줄 수 있습니까'): -1. '-시-' used one extra time (e.g. '주실 수 있으십니까'): no deduction.
W03 Copying a short phrase immediately before the blank (e.g., '서류를 준비하다가', '이 사진을 보시고'): -1. Copying the whole clause before the blank (e.g. '출근 전에 급하게 서류를 준비하다가'), or writing two or more sentences: -2. Mentioning a noun such as '통장 사본' or '월급' again does not count as copying.
W04 The blank is followed by a question mark, but the answer is a statement or a command (e.g. '-고 싶습니다', '-기 바랍니다', '-았/었으면 좋겠습니다', '-아/어 주세요', '-아/어 주십시오'): -2.
W05 Too vague: only "I made a mistake" or "there is a problem": this blank gets 2 points at most. Only a general idea (e.g. in ㉠, only saying the documents were not handled well, without saying it was the '통장 사본'; in ㉡, only '확인해 주실 수 있습니까', without saying what the boss should do): this blank gets 3 points at most.
W06 The tense contradicts the context (e.g. something that already happened yesterday written as '-(으)ㄹ 것 같습니다'): this blank gets 2 points at most.
W07 A word choice that changes the meaning (e.g. '예금하다' from English "deposit": '예금' means keeping money in a bank account as savings; money paid into someone's account is '입금'. So it is the wrong word for an employer paying wages into your account; use '넣어 주다', '보내 주다' or '입금해 주다'): -2. Only slightly unnatural: -1.
W08 A wrong or missing particle (e.g. "into my account" written as '제 계좌에서'; it should be '제 계좌에' or '제 계좌로'; "into the envelope" written as '봉투에서'; it should be '봉투에'): -1 for each one.
W09 A spelling, conjugation or spacing mistake (e.g. '넣지 안았습니다' should be '넣지 않았습니다', '너어' should be '넣어', '않았는 것' should be '않은 것', '빠뜨린것' should be '빠뜨린 것'): -1 at most per blank, however many there are.
